Ayuda de Actividades

Esta pantalla muestra todas las actividades registradas para el proyecto.

Acciones disponibles:

  • Ver actividades: lista completa de actividades del proyecto actual.
  • Editar actividades: dentro de la lista puedes acceder a edición o actualización.
  • Generar reporte PDF: descarga un informe con toda la información del libro mayor del proyecto.

Secciones principales:

  • Encabezado: muestra el módulo actual: información, cronograma y cotización.
  • Generar Reporte: botón rápido para obtener un archivo PDF.
  • Lista de actividades: tabla con actividades, fechas, estado y acciones de edición.

Tip: usa esta vista para controlar y actualizar el avance del cronograma del proyecto.
